工作室 / Agents

Agents

管理 Agent 的角色、指令和能力。需要調整流程時，再進畫布接線。

Agent狀態

此版本只用本機範例資料，不會派工或執行程式。

元件畫布

100%
從 Skill 或 Tool 拉線到 Agent也可依序點兩個接點

元件庫

拖到畫布，或點一下加入。

接線設定

變更會同步到 Agent 原設定。

Skill Tool

元件接線只修改設定，不會執行工具。

Agent 設定

先定義它是誰、怎麼做事。需要接線時，再開流程畫布。

能力

勾選要保存在設定檔裡的能力。加入流程時可重用這組能力。

共用 Skills

Agent 只記錄技能 ID，不會複製指令。共用技能更新後，所有引用一起更新。

共用 Tools

為此 Agent 選擇工具與權限。這裡只設定，不會查詢或讀寫檔案。

檢查組態

唯讀測試入口

只可讀取固定的 Rust 測試檔。寫入沒有實作，也不會自動呼叫模型。

工作室 / Skills

Skills

把重複使用的工作指令存成獨立技能。不同 Agent 可引用同一份。

預覽只管理文字和引用，不會執行技能指令或腳本。

新增 Skill

name 是引用 ID，例如 review-rust。第一次儲存後固定；描述與指令可隨時改。

這次修改會影響誰

工作室 / Tools

Tools

定義工具能做什麼。各 Agent 只能從工具支援的操作裡選擇自己的權限。

本版不連接或執行工具。

新增 Tool

在這裡定義工具的能力上限，到 Agent 設定時再逐項授權。

支援的操作

唯讀試跑

固定測試檔

先下載範本，再選取該檔。試跑前核對檔名及 SHA-256；不會讀其他檔案、掃描資料夾或修改檔案。

    

    

    

    交給模型審查
    可下載審查請求，檢查內容後再自行交給已授權的模型。工作室不會自動傳送。

    快捷鍵
    

    Ctrl+Enter執行流程
    

    雙擊空白處搜尋並加入節點
    

    點輸出 → 點輸入不用拖曳也能接線（Esc 取消）
    

    空白鍵 + 拖曳／中鍵拖曳平移畫布
    

    方向鍵平移畫布或移動選取的節點
    

    滾輪、+ / −縮放
    

    Shift+點選、框選多選節點
    

    Ctrl+A全選
    

    Ctrl+C / Ctrl+V複製／貼上
    

    Ctrl+Z / Ctrl+Y復原／重做
    

    Delete刪除選取的節點
    

    Ctrl+B略過（bypass）選取的節點
    

    Ctrl+M停用（mute）選取的節點
    

    Ctrl+G把選取的節點加入群組
    

    Esc取消接線或關閉抽屜
    

    在輸入框裡打字時，畫布快捷鍵不會作用。
